# Місія 02 · Пара 04 — Один продукт — багато сторінок

90 хвилин, 10 клас. На основі вихідних файлів Пари 03, без зміни базової дизайн-системи та денної/нічної тем.

## Новий результат
Внутрішня сторінка власного продукту в Desktop, Tablet і Mobile; візуальна спорідненість із головною; план зрозумілої навігації; ШІ-аудит.

## Послідовність
1. Аудит та імпорт JSON Пари 03 — 10 хв.
2. Теорія спорідненості, навігації, структури та адаптації — 15 хв.
3. Desktop внутрішньої сторінки — 20 хв.
4. Tablet і Mobile — 25 хв.
5. ШІ-аудит — 15 хв.
6. Рефлексія, TXT/JSON — 5 хв.

**Не вивчаємо повторно:** створення кнопок, палітри, дизайн-системи, Sitemap, User Flow або головної сторінки. Прототипування — Пара 05.

Відкрити `index.html` у браузері. Для GitHub Pages розмістити всю папку `pair-04/` в корені репозиторію.

Автозбереження використовує LocalStorage; експорт JSON потрібний для перенесення даних між пристроями. Не видаляйте оригінальний JSON Пари 03.

## Аудит і виправлення
- CSS повністю успадковано з Пари 03 (додані лише стилі навчальних ілюстрацій).
- Ілюстрації 2.3, 2.4, 2.5 окремі та не дублюються.
- Промпти розділу 05 розміщено в акордеонах, закритих за замовчуванням.
- Навчальний зміст і логіку імпорту/експорту не змінено.
