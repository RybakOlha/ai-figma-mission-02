# AI × Figma · Місія 02 / Пара 01

Інтерактивний навчальний модуль для 10 класу (90 хв). Українська мова.

## Вміст
- `index.html` — семантична навчальна сторінка (без вбудованих CSS/JS)
- `assets/css/styles.css` — адаптивні стилі, світла/темна тема
- `assets/js/app.js` — автозбереження, чеклісти, журнал рішень, експорт TXT/JSON та імпорт JSON
- `assets/images/*.svg` — 5 оригінальних навчальних схем
- `INSTRUCTIONS_TEACHER.md` — методичні рекомендації

## Публікація на GitHub Pages
1. Створіть публічний репозиторій у GitHub.
2. Завантажте **вміст** цієї папки в корінь репозиторію: `index.html`, `assets/`, документи та `.nojekyll`.
3. У Settings → Pages оберіть Deploy from a branch → main → /(root).
4. Відкрийте отримане посилання. Перевірте експорт TXT і JSON.

## Використання
Сторінка працює без сервера і без підключення до LLM. Учень працює з Figma та зовнішнім дозволеним ШІ-чатом окремо. Дані зберігаються у localStorage поточного браузера; перед зміною пристрою обов'язково експортуйте JSON. У Moodle здається TXT. Не розміщуйте особисті або конфіденційні дані у промптах.

## Обмеження
Дані з Місії 01 автоматично не імпортуються: це інша структура JSON. Покликання й висновки з Місії 01 учень переносить вручну. Вбудовані навчальні ілюстрації не є макетами Figma. На 90-хвилинній парі всі сторінки мають бути накреслені хоча б на базовому рівні; деталізація залежить від обсягу MVP.


## Імпорт із Місії 01
На початку сторінки кнопка «Імпортувати JSON Місії 01» приймає `format: ai-figma-design-audit`, `pair: 1`, `version: 1`, `answers`. Переносить назву, проблему й URL Figma; відображає аудит; інші поля Місії 02 не змінює. Власний JSON Місії 02 відновлюється окремою кнопкою внизу.
