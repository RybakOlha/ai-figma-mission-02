# Місія 02 · Пара 03 — ілюстрована версія для перевірки

Відкрийте `index.html` у браузері. У розділі 02 відкрийте акордеони 2.2–2.5.

- 2.2: навчальні ширини та перевірка 320 px.
- 2.3: окремі схеми Flow, Gap, Padding, Alignment.
- 2.4: погоджена ілюстрація без змін.
- 2.5: практичний орієнтир 44×44 px без хибної універсальної вимоги ширини кнопки.

Додано мініпрактику під кожною ілюстрацією. Інші розділи та JavaScript не змінено.
Це версія для візуального і функціонального перегляду, не публікувати до схвалення.
